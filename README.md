#### 🏎️ [8086 Assembly Car Racing Game](https://github.com/Plagiaryze2/Assembly-Car-Racing-Game)
A retro 16-bit DOS game that renders assets directly to the VGA display buffer and hooks native CPU interrupts.
- **Tech Stack**: 8086 Assembly, NASM, DOSBox
- **Highlights**: Custom timer (`ISR 08h`) and keyboard (`ISR 09h`) interrupt handlers, double buffering, and custom LCG random seed generator.
